# Hostel Occupancy & Revenue Dashboard

A working web application that shows a college hostel's occupancy and revenue on a dashboard. Built with **Streamlit + SQLite** — pure Python, no HTML/CSS/JavaScript required.

## What it shows

- **Occupancy rate %** — occupied beds vs total beds
- **Total revenue** — room rent + mess (food) fees
- **Monthly trends** — occupancy and revenue over time
- **Room type comparison** — single / double / triple performance
- **Weekday analysis** — mess attendance drops Fri–Mon (students go home)
- **Admin data entry** — add new bookings and mess entries live

## Tech stack

| Layer | Technology |
|-------|------------|
| Frontend + Backend | Streamlit (Python) |
| Database | SQLite (single file `data/hostel.db`) |
| Data generation | Python + Faker + pandas |
| Charts | Plotly |
| Language | Python 3.11+ |

## How to run locally

### Prerequisites
Python 3.11+ installed on your computer.

### Step 1: Create a virtual environment
```bash
cd hostel-dashboard
python -m venv venv
```

### Step 2: Activate the virtual environment
- **Windows:** `venv\Scripts\activate`
- **Mac/Linux:** `source venv/bin/activate`

### Step 3: Install dependencies
```bash
pip install -r requirements.txt
```

### Step 4: Generate and build the database
```bash
python scripts/generate_data.py
python scripts/clean_data.py
python scripts/build_database.py
```

### Step 5: Run the app
```bash
streamlit run app/app.py
```

The dashboard opens at `http://localhost:8501`.

## How to deploy (Streamlit Community Cloud — free)

1. Push this repo to GitHub (make it **public**)
2. Go to https://share.streamlit.io
3. Click **New app** → connect your repo → main file: `app/app.py` → **Deploy**
4. Your dashboard gets a public URL

Note: `data/hostel.db` is gitignored. For Streamlit Cloud, either commit the DB file or have the app regenerate it on first run.

## KPI definitions

All KPIs are defined in `queries/kpis.sql`:

| KPI | Formula |
|-----|---------|
| Occupancy Rate | (Occupied Beds / Total Beds) × 100 |
| Total Hostel Revenue | Room Rent Revenue + Mess Fee Revenue |
| Room Rent Revenue | SUM of paid hostel_fee payments |
| Mess Fee Revenue | SUM of mess_charge for meals availed |
| Revenue per Occupied Student | Total Revenue / Number of Occupied Students |
| Revenue per Available Bed | Total Revenue / Total Available Beds |
| Vacancy Rate | (Vacant Beds / Total Beds) × 100 |
| Monthly Revenue Growth % | ((This Month − Last Month) / Last Month) × 100 |
| Profit Margin % | ((Total Revenue − Total Expenses) / Total Revenue) × 100 |

## Data disclosure

⚠️ **All data in this project is synthetic (fake but realistic).** No real student, room, or payment data is used. The data was generated with a Python script using the Faker library, following the occupancy patterns, weekend mess drop, and semester billing described in the business case. Intentional data-quality issues (duplicates, missing values, inconsistent date formats) were included to demonstrate the data-cleaning step.
